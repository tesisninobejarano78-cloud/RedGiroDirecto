# Hagberg, Schult y Swart (2008): NetworkX

**Referencia**: Hagberg, A. A., Schult, D. A. y Swart, P. J. (2008). Exploring network structure, dynamics, and function using NetworkX. En G. Varoquaux, T. Vaught y J. Millman (eds.), *Proceedings of the 7th Python in Science Conference (SciPy 2008)* (pp. 11–15).

Acceso: <https://doi.org/10.25080/TCWV9851>

## Qué propone

Presenta NetworkX, una librería de Python para explorar y analizar redes.

## Para qué la usa el proyecto

- Es la librería con que se construyen las dos redes y se calculan las métricas que trae de serie. Lo que no trae está en `redes_metodos.py`.
